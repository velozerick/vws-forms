# vws-forms


Aplicación web desarrollada con Flask para la gestión de formularios y recopilación de información de clientes.

Este proyecto forma parte del aprendizaje práctico de Flask enfocado al desarrollo backend con Python.

---

# Objetivos del proyecto

- Aprender Flask mediante un proyecto real
- Comprender el flujo request/response
- Trabajar formularios web
- Implementar validaciones backend
- Practicar estructura profesional de proyectos
- Preparar futuras integraciones con PostgreSQL
- Realizar despliegues en Linux
