About Flask

Flask es un microframework de Python que sirve para construir aplicaciones web sencillas y flexibles.

¿Por qué elegir Flask?

Flask ofrece una base ligera que te permite agregar solo lo que necesitas, ideal para proyectos pequeños o prototipos rápidos.

Características principales

  • Rutas sencillas con decoradores.
  • Renderizado de plantillas HTML con Jinja2.
  • Control de solicitudes HTTP y formularios.
  • Ampliable con extensiones cuando el proyecto crece.

Flujo básico de una app Flask

  1. Importar Flask y crear la aplicación.
  2. Definir rutas con @app.route.
  3. Escribir funciones que devuelven HTML o renderizan plantillas.
  4. Ejecutar la app en modo debug durante desarrollo.

Comparación rápida

Concepto Descripción
Flask Microframework web en Python, fácil de configurar y usar.
Jinja2 Motor de plantillas que permite insertar variables y lógica en HTML.
Rutas Permiten definir qué contenido se muestra en cada URL.
Debug Modo de desarrollo que recarga la app al guardar cambios.

Ejemplo de código

Un pequeño ejemplo de la estructura típica de Flask:

from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    return render_template('home.html')

if __name__ == '__main__':
    app.run(debug=True)

Ventajas de Flask

  • Rápido de aprender.
  • Flexible y personalizable.
  • Perfecto para APIs y pequeños sitios web.
  • Gran soporte de la comunidad.
